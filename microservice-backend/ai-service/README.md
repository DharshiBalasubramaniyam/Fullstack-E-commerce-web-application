An intelligent shopping assistant powered by <b>Agentic AI</b>, 
capable of understanding user requests, 
collaborating with specialized domain agents, 
and interacting with backend microservices via MCP to deliver a seamless shopping experience.

✨ Features
- 💬 Natural language conversations
- 🧠 Multi-agent architecture using LangGraph
- ⚡ FastAPI backend
- 🤝 MCP (Model Context Protocol) tool integration
- 💾 MongoDB checkpointing for conversation state
- 🧑‍💻 Human-in-the-loop (interrupt-based approvals using LangGraph interrupts)
